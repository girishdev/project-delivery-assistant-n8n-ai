MUJ-Deloitte Project 02 - Consulting or Project Delivery Assistant

STEP 1 SAMPLE INPUT FILES
1. Project_Plan.pdf - baseline project scope, owners and milestones.
2. Meeting_Transcript_01.txt - initial progress, tasks and early risk.
3. Meeting_Transcript_02.txt - follow-up with missed milestone, revised targets and blockers.

These are SYNTHETIC documents intended for a demonstration. No real company data is included.

HOW TO USE WITH n8n
- Upload the PDF and either transcript through an n8n form, or use form text fields if binary extraction proves difficult.
- Extract PDF text and read TXT text. Keep project plan and transcript clearly separated.
- Ask an AI model to produce meeting summary, action items (with owner and due dates), risks, milestone differences and a draft status report.
- Present all output for Project Manager review before approval.
- Use the second transcript to show that the original baseline is missed but not formally revised.

IMPORTANT
This package contains input documents only. It does not include an n8n workflow, generated AI results or approval implementation; those belong to later project steps.
